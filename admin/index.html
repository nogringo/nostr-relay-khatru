Banned pubkeys

A banned pubkey can no longer publish here, and everything it already published is deleted. Its deletion and vanish requests are still accepted, so it can always take its data back.

    No pubkey is banned.

    Banned events

    A banned event is deleted and refused if anyone publishes it again. Deletion and vanish requests cannot be banned.

      No event is banned.

      Blocked IP addresses

      A blocked address cannot open new connections, and its open ones can no longer publish or subscribe. This relies on the reverse proxy sending X-Forwarded-For.

        No address is blocked.

        Refused kinds

        New events of a refused kind are turned away. Stored ones stay. Kinds 5 and 62 are always accepted.

          Every kind is accepted.

          Relay info

          What clients read in the NIP-11 document. Saved values take precedence over RELAY_NAME, RELAY_DESCRIPTION and RELAY_ICON.

          Backup

          A zip of every stored event, one per line in events.jsonl, and of the moderation decisions and relay info in admin.json. It holds the gift wraps and the deletions only their authors can read: keep it as private as the server.
